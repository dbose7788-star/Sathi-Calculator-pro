# Sathi Feature Roadmap

## Current Status
- APK #6 successfully built.
- Trial restriction removed.
- GitHub Actions build workflow is working.
- Current APK shows the basic Standard calculator.

## Features To Implement

1. Standard Calculator
   - Professional calculator interface
   - Basic arithmetic
   - Percentage
   - Decimal calculations
   - Clear and backspace

2. Scientific Calculator
   - Scientific functions
   - DEG/RAD modes
   - Trigonometry
   - Logarithms
   - Powers and roots
   - Constants

3. Goods / Material Calculator
   - Quantity
   - Rate
   - Total amount
   - Material/goods calculations
   - Useful business calculation tools

4. History
   - Store calculations
   - View previous calculations
   - Reuse previous results
   - Clear history

5. Settings
   - Calculator preferences
   - Scientific mode preferences
   - Theme/interface settings
   - App information

6. Navigation
   - Standard
   - Scientific
   - Goods/Material
   - History
   - Settings

## Quality Requirements
- Fully functional app, not a mockup.
- Safe expression parsing.
- High/arbitrary precision arithmetic where required.
- No silent rounding.
- Preserve existing working functionality.
- Build and test through GitHub Actions.
- Test the resulting APK on the Android phone.

## Development Rule
Implement and test features step by step.
Do not replace working code unnecessarily.
